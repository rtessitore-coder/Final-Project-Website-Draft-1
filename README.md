# Ryan Tessitore portfolio site

Plain HTML and CSS, no build step. Pages: `index.html`, `about.html`, `projects.html`, `resume.html`, `contact.html`. Shared styles in `styles.css`.

**Open it:** double-click `index.html`.
**Publish it:** upload the contents of this folder (so `index.html` is at the top) to a public GitHub repo and turn on Pages (Settings, Pages, branch main, folder root).

## Find what is left to do
Every piece of placeholder text starts with `[PLACEHOLDER]` and is highlighted yellow. Search the folder for that word.

## Before publishing
- `resume.pdf` is a copy of the résumé from `Website Information/`. It contains a phone number and a GPA. Replace it with a version you are comfortable making public.
- Confirm the NAICS code at census.gov/naics.
